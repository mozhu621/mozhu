# 基金从业 · 本机账号学习室

https://mozhu621.github.io/mozhu/

用户名和密码在当前浏览器注册与校验，账号之间分别保存学习记录。网站不连接 ChatGPT 或其他账号服务。密码以随机盐和 PBKDF2-SHA256（210000次）保存摘要，学习记录没有加密。本机登录不是服务器安全认证。

关闭标签页后需重新登录；清理浏览器数据会删除账号与记录。请使用“记录备份”导出并在其他设备注册本机账号后导入。忘记密码无在线找回服务。旧云端账号不能在这里登录。

包含科目1与3、322道题、48张重点卡、错题复习和每科100题120分钟模拟考试，每题1分，60分合格。

构建：npm ci && npm run build。检查：npm test。源码位于 src/。
