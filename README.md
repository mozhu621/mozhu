# 基金从业 · 冲刺学习室

科目1与科目3：322道精选题、48张重点卡、错题解析、5/8/10小时计划，以及每科100题、120分钟、每题1分、60分合格的模拟考试。

## 开启网页

本仓库由 mozhu621 用于发布基金从业学习网站。

在仓库 Settings → Pages 中，选择 Deploy from a branch，然后选择默认分支的 /(root)，点击 Save。GitHub 完成发布后，该页面会显示正式网址。

## 账号与记录

- 网页由 GitHub Pages 托管。账号、错题和成绩继续保存在已有账号服务中。
- 点击“登录 / 注册学习账号”后，到账号服务中登录；完成后会返回本学习室。旧账号无需重新注册。
- GitHub 不存放用户密码或个人学习记录。仓库中只有公开网页和学习题库。
- 登录会话保存在当前标签页的会话存储中，24小时后失效；关闭标签页或换设备后重新登录即可恢复云端记录。
- 账号服务： https://fund-exam-sprint-0922.mozhu621.chatgpt.site

源码说明：本仓库为可直接发布的静态产物，study.js 为学习应用，pages-client.js 负责连接账号服务，content.json 为题库与重点卡。

本题库用于备考学习，非协会发布的官方题库；具体来源与2026年规则入口见网站“资料与更新”。
